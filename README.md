# HMI Online Technical Manual v3.7 — GitHub Pages

Статична веб-інструкція для HMI насосної групи 3 × 5,5 кВт.

## Розгортання
Розпакуйте **вміст архіву** у корінь репозиторію GitHub Pages та виконайте Commit/Push. `index.html` має лежати в корені.

## Важливо при оновленні з v2.x / v3.0
Старі версії використовували cache-first service worker. v3.7 його відключає та очищає старі кеші. Якщо після першого Push браузер ще показує стару або змішану версію, один раз відкрийте:

`https://ВАШ-ЛОГІН.github.io/ВАШ-РЕПОЗИТОРІЙ/reset-cache.html`

Після очищення сторінка автоматично повернеться до актуальної інструкції.

## Архітектура
- HTML/CSS/vanilla JS
- GitHub Pages, без backend
- tree navigation + search + scroll-spy + deep links
- responsive drawer
- interactive HMI explorer
- lightbox
- print stylesheet
