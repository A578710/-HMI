# HMI 3×5,5 кВт — інтерактивний технічний довідник

Статичний вебзастосунок для GitHub Pages. Основний режим — **інтерактивна модель HMI**: користувач вибирає екран, натискає об’єкти інтерфейсу та отримує технічний опис, значення для оператора, рівень доступу і пов’язану процедуру.

## Основні модулі

- Інтерактивна модель операторського інтерфейсу;
- карта екранів HMI;
- реєстр об’єктів поточного екрана;
- повна ієрархія «НАЛАШТУВАННЯ»: ОСНОВНІ, ЗАТРИМКИ, ДВИГУН / ПЧ, PID РЕГУЛЮВАННЯ;
- 4 окремі сторінки групи «СЕРВІС» з параметрами, командами та діагностичними станами;
- опис робочих параметрів, впливу на систему та індикації;
- операторські процедури;
- журнал, аварії, автоматичні режими та первинна діагностика;
- PWA та офлайн-кеш після першого відкриття.

> **Демонстраційний режим:** вебзастосунок не передає команди в PLC або ПЧ і не є каналом керування обладнанням.

## Розгортання на GitHub Pages

1. Завантажте **весь вміст цієї папки** у корінь GitHub-репозиторію.
2. Відкрийте **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: **main**, Folder: **/(root)**.
5. Натисніть **Save**.
6. Після deployment сайт буде доступний за `https://USERNAME.github.io/REPOSITORY/`.

Усі шляхи відносні, тому сайт коректно працює в підкаталозі GitHub Pages.

`robots.txt` і `noindex` не є контролем доступу. Звичайний GitHub Pages слід вважати публічним для всіх, хто знає URL.
