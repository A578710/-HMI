# HMI Operator Guide v2.4

Операторська веб-інструкція HMI насосної групи 3 × 5,5 кВт.

## Призначення
Версія для щоденної роботи оператора: головний екран, робочі параметри, графік, тренди, журнал, аварії, автоматичні режими та первинна діагностика. Сервісні сторінки не публікуються в цій версії.

## GitHub Pages
1. Завантажте вміст папки у корінь репозиторію.
2. Settings → Pages → Deploy from a branch.
3. Branch: main, folder: /(root).

Cache: `hmi-operator-guide-v2-4`.
